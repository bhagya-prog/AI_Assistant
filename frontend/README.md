# AI Assistant Frontend

React + Vite client for the AI assistant.

## Features

- Modern chat UI with dark/light mode
- Assistant status panel (model, RAG doc/chunk counts)
- PDF upload + indexing for RAG
- Quick prompt chips
- Tool/source metadata in responses

## Run

```bash
npm install
npm run dev
```

## Optional env

Set API base URL:

```bash
VITE_API_BASE_URL=http://localhost:5000
```
